# 챗봇 내 조건 이미지 저장

2026-11-16 / 기준 main: 09a11df / 작업 브랜치: feature/chatbot-condition-card

## 사용 방법

1. 챗봇에서 식단과 알레르기 여부·항목을 확인합니다.
2. 하단 **내 조건 → 내 조건 이미지 저장**을 누릅니다.
3. 한국어와 선택 언어를 함께 표시한 카드 미리보기가 열리고 PNG 저장을 시도합니다. 자동 저장이 제한되는 환경에서는 **PNG 이미지 저장**, 지원 기기의 **이미지 공유**, 이미지 길게 누르기를 이용할 수 있습니다.

한국어는 항상 표시하며 영어·중국어·일본어 선택 시 항목별로 해당 언어도 함께 표시합니다. 한국어를 선택한 경우에는 중복 없이 한국어만 표시합니다. 식단 설명과 확인 문구도 두 언어로 들어갑니다. 식단, 알레르기, 추가 제외, 선호 음식·재료, 맵기와 원료·교차 접촉 확인 문구를 포함합니다. 알레르기와 선호 항목을 구분하며, 미확인 응답은 없음으로 바꾸지 않습니다. 기본 선택은 없음이지만 질문을 완료하기 전에는 이미지를 만들 수 없습니다. 충돌하거나 범위가 미확정인 조건도 먼저 확인해야 합니다. 긴 조건은 이미지 높이를 늘려 표시합니다.

사용자 선택에 따라 **이미지 저장만** 추가했습니다. 마이페이지·서버에 조건을 추가 저장하지 않습니다. 기존의 선택형 대화 복구 저장은 유지했습니다.

## 함께 변경한 사항

- 회원가입 국가는 빈 선택에서 시작하며 직접 선택해야 합니다. 화면, 인증 호출, 서버 회원가입 모두 빈 값·누락·잘못된 코드를 거부합니다. 기존 회원의 국가는 변경하지 않습니다.
- 웹·모바일 실행 버튼에는 사용자 제공 원본 PNG를 사용했습니다. 파일을 재생성하지 않고, 버튼에서 바깥 여백을 가려 아이콘을 표시했습니다.
- 변경한 진입 스크립트와 스타일의 캐시 버전을 갱신했습니다.

## 확인 결과와 범위

- 최신 main 동기화 후 독립 실행 테스트 43개 모두 통과했습니다. 여기에는 4,643건 추천 시뮬레이션과 기존 iframe을 재사용하는 메인 언어 전환 검사가 포함됩니다. 정적 빌드와 변경 파일 형식 검사도 통과했습니다.
- 로컬 웹 1280×720 및 모바일 브라우저 390×844에서 팝업/전용 페이지, 새 아이콘, 조건 카드 미리보기를 확인했습니다.
- 메인 언어 선택에서 영어 → 중국어 → 일본어 → 한국어로 변경했습니다. 기존 iframe을 재생성하거나 새로고침하지 않고 챗봇 언어가 변경됐고 우유·유제품 및 땅콩 선택이 유지됐습니다. 카드는 한국어를 유지하며 선택 언어를 병기합니다. 영어 UI에서 한국어와 영어 알레르기가 함께 그려진 최종 미리보기도 확인했습니다 (`bilingual-en.jpg`).
- 실제 앱이 생성해 화면에 표시한 PNG를 읽어 검사용 파일로 보존했습니다. 예시 6개 알레르기 카드: 820×1145 PNG. 실제 건강 정보가 아닌 테스트 선택입니다.
- 확인 브라우저는 iframe의 blob 다운로드를 지원하지 않았고, data 주소의 직접 다운로드 확인도 URL 보안 정책에 의해 차단했습니다. 이미지 생성·미리보기·다운로드 링크 구성은 확인했지만 실제 휴대폰 사진 앱 저장이나 운영 배포는 확인하지 않았습니다.
- 로컬 API의 서버 연결 설정이 없어 브라우저의 실시간 DB 추천은 이번 화면 검사에 포함하지 않았습니다. 추천 시뮬레이션은 저장소 음식 및 통제된 테스트 데이터 기준입니다.

증거: `docs/verification/condition-card/`의 화면, PNG, 언어 확인 기록과 테스트 결과입니다. 기존 프로필 사진 테스트의 최신 지원 정보 API 모의 응답 누락도 보완했습니다.
