# 챗봇 로컬 디자인 확인안

2026-11-17 / branch: feature/chatbot-local-design / 최신 반영 main: 9fdb0be

확인 주소: http://127.0.0.1:8783/#/chatbot

`tools/preview-chatbot-fixture.cjs`를 실행한 로컬 확인 화면입니다. 저장소 음식 43개를 모의 API로 제공하며, 운영 Supabase에 연결하거나 쓰지 않습니다. 공개 사이트에 배포하지 않았습니다.

## 변경 방향

1. **현재 질문에 집중**: 완료한 질문의 폼·선택지를 접습니다. 이전 선택지는 펼쳐 읽을 수 있고, 이미 완료한 입력은 수정되지 않도록 비활성화합니다. 새 답변을 보내면 이전에 열었던 선택지도 다시 접습니다. 초기 로딩 완료 안내가 첫 질문보다 길게 나오던 부분도 정리했습니다.
2. **세 단계 진행 표시**: 식단·알레르기 → 음식 취향 → 확인·추천. 실제 단계는 기존 규칙을 유지하고 표시만 묶었습니다. 현재 조건은 접어 볼 수 있습니다.
3. **간결한 추천 카드**: 작은 사진, 음식명, 주재료, 원문·알레르기 확인 안내를 먼저 보여줍니다. 상세 설명은 음식 정보 버튼으로 확인할 수 있습니다. 추천 결과가 나오면 첫 추천과 주의 문구부터 보이도록 스크롤합니다. 안전성 확인 안내는 줄임 처리하지 않습니다.
4. **직원용 내 조건 카드**: 저장 버튼을 카드 상단에 두고 알레르기·식단·제외·선호·맵기·종류를 구분합니다. 여러 재료의 포함 방식과 비건 후보 확인 방식도 유지합니다. 대화 복구·JSON 내보내기는 기록 관리에 접어 두었습니다. PNG의 한국어 및 선택 언어 병기 기능은 그대로입니다.

아이보리·베이지·붉은 강조색, 기존 음식 및 추천 규칙과 모바일 전용 화면/웹 팝업 구조는 유지했습니다. 앞서 로컬에 반영한 아이콘 높이 기반 스크롤 여유와 브라우저 호환성 설정도 보존했습니다.

## 확인

- 땅콩 알레르기 → 육류 → 소고기 → 추천 흐름을 실제 버튼으로 진행했습니다.
- 완료 선택지 5개가 접히고 현재 응답만 강조됐습니다. 이전 선택지를 펼쳐도 조건이 그대로였고 이전 컨트롤은 비활성 상태였습니다.
- 320·360·390·640px에서 조건 카드의 문서 가로 넘침을 확인했습니다. 웹 1280×720 팝업과 모바일 390×844에서 첫 질문·추천·조건 화면을 확인했습니다.
- 메인의 언어 선택 및 확인을 통해 en → zh → ja → ko로 전환했습니다. 기존 iframe을 사용하면서 새 문구와 조건 요약이 바뀌고 땅콩·소고기 선택이 유지됐습니다. 최신 메인은 언어 선택 화면에서 실행 버튼을 숨기므로 언어 확인 후 홈에서 다시 열어 검사했습니다.
- 진행 단계·미확인/충돌·다국어 조건 요약·재료 선호와 알레르기의 구분·기존 포함 방식 유지 검사를 추가했습니다.
- 실제 iOS/Android 기기 및 네이버 앱 브라우저 검사는 아닙니다. 이번 디자인 작업에서 휴대폰 사진 앱 저장 완료 여부는 재검사하지 않았습니다.

스크린샷과 테스트 기록: `docs/verification/chatbot-design-review/`.

## 다국어·기능 통합 재검사 (2026-11-17)

검사 중 발견한 두 문제를 수정했습니다.

- 언어 변경 시 아직 제출하지 않은 식단·알레르기·재료·맵기 선택이 초기화되던 문제: 현재 질문의 입력값을 보존하고 같은 질문에만 복원합니다. 작성 중인 메시지도 유지됩니다.
- 언어 변경 후 완료 질문을 펼치면 기본 선택값이 보이던 문제: 해당 질문에 실제 제출한 답변을 적용한 뒤 보관하도록 수정했습니다. 대화 복구에서도 같은 처리를 사용합니다.

한국어·영어·중국어·일본어에서 제출 전 선택 및 제출한 조건을 확인했습니다. 우유·땅콩 알레르기, 돼지고기 제외, 소고기 선호, 순한맛을 함께 입력해 추천을 진행했고 언양불고기 1개가 나왔습니다. 추천에는 식당에서 실제 재료와 교차 접촉을 확인해야 한다는 안내가 유지됩니다. 선호와 제외는 별도 항목으로 유지됐습니다.

음식 상세 → 식당 상세 → 앱 지도 이동과 챗봇 재진입을 검사했습니다. 상세 창이 열리면 부모 닫기 버튼의 클릭이 차단되어 겹치지 않았습니다. 대화 저장·새로고침·복구 후에도 조건이 같았고, 검사에 사용한 대화 저장 설정은 다시 해제했습니다. 320px·390px 및 1280px 웹 환경에서 조건 화면에 가로 넘침이 없었습니다.

최종 정적 빌드, 자동 테스트 파일 45개, git diff --check가 통과했습니다. 자동 검사에는 다국어 해석·추천 시뮬레이션 4,643건과 한국어+선택 언어 조건 이미지 모델 검사가 포함됩니다. 증거는 `docs/verification/chatbot-integration-20261117/`에 저장했습니다.

범위: 저장소 음식 43개의 모의 DB를 사용한 로컬 검사입니다. 운영 DB·공개 배포·실제 네이버 앱/휴대폰은 검증하지 않았습니다. 모의 서버는 Google 지도 키를 제공하지 않으므로 지도 화면 이동과 대체 안내까지 확인했으며 실제 지도 SDK 표시는 검증하지 않았습니다. 실제 기기의 이미지 다운로드 및 사진 앱 저장 완료는 별도 확인이 필요합니다. 브랜치 푸시나 PR은 하지 않았습니다.
