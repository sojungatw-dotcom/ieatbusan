## 추가 수정한 동작

- `I don't like pork` / `我不喜欢猪肉` / `豚肉は食べたくない`: 돼지고기 제외로 저장합니다.
- `I am allergic to peanuts, shrimp and milk`: 땅콩·새우·우유를 모두 유지합니다.
- `I want tofu` / `달걀 먹고 싶어`: 선호를 누락하지 않습니다. 직접 요청한 조건은 다음 선택 화면에서도 유지합니다.
- `No pork` 이후 `I want pork`: 제외를 자동으로 해제하거나 새 선호를 조용히 버리지 않고 충돌을 확인합니다.
- `I want Bokguk but no Bokguk`: 같은 음식이 반복돼도 제외를 놓치지 않습니다.
- `No allergies except peanuts`: 땅콩 알레르기를 놓치지 않습니다.
- `우유 알레르기는 없어` / `I have no milk allergy`: 기존의 다른 알레르기를 전부 지우지 않습니다. 설정에서 검토하도록 안내합니다.
- `I don't like spicy food`: 매운 음식 선호로 바꾸지 않고 낮은 맵기로 반영합니다.
- `Is this dairy-free?`: 질문을 유제품 제외 지시로 단정하지 않습니다.
- 영어 예시 대화에 남던 `시작` 및 후보 음식 원명, `1 items` 표현을 수정했습니다. 메뉴 원명·주문 카드에서 의도적으로 표시하는 한국어는 유지합니다.
- 엄격한 비건 모드에서는 확인 표시가 있어도 동물성 재료 포함 가능성이 명시된 모순 기록을 제외합니다. 확인 필요 후보 보기를 사용자가 허용한 모드와 구분합니다.

브라우저에서도 영어 `I don't like pork, I want beef and I am allergic to peanuts` 입력 후 **선호 Beef / 제외 Pork / 알레르기 Peanut**을 확인하고, 선택 화면을 지나 실제 후보 3개가 나올 때까지 조건이 유지되는 것을 확인했습니다. 같은 음식에 대한 선호·제외 충돌 화면도 확인했습니다. 가상 bootstrap 응답을 사용했으며 운영 데이터는 수정하지 않았습니다.

## 남아 있는 확인 사항

- 원어민 감수나 모든 문장의 언어적 정확성을 보장하는 검사는 아닙니다. 핵심 필드의 누락·의미 표지와 대표 대화 흐름을 대조한 결과입니다.
- 등록되지 않은 표현·재료, 인용·복잡한 생략·반어 등의 의미는 여전히 규칙 처리 범위를 벗어날 수 있습니다. 확정할 수 없을 때는 선택 화면으로 확인합니다.
- 실제 운영 DB 연결·최신 DB 데이터의 원료 정확성·식당별 실제 조리·교차 접촉·비건/할랄 인증은 이 시뮬레이션으로 검증하지 않았습니다.
- 예산·거리·실시간 영업·할랄은 구조화된 확인 데이터가 없어 계속 미확인으로 안내합니다.
