# 챗봇 제한 조건·전송·언어 전환 검사

기준: 2026-11-18, 최신 main `51b5d27` (PR #30 되돌리기 반영). 이전 디자인 PR을 다시 적용하지 않았습니다. 브랜치: `fix/chatbot-strict-diet-flow`.

## 수정 범위

챗봇의 제한 조건·입력 처리·대화 테두리, 언어 선택 화면 안내 카드의 정렬만 수정했습니다. 메인 HTML과 챗봇 위젯 파일은 수정된 챗봇 파일 및 언어 스타일의 캐시 버전만 바꿨습니다. 다른 화면의 기능·디자인과 DB는 변경하지 않았습니다.

## 원인과 수정

- 비건 선택 후 다음 버튼 대신 문장을 보내면 화면의 선택값이 추천 상태에 적용되지 않았습니다. 문장이 있으면 문장을 요청으로 처리하되, 화면에서 수정한 식단·알레르기·제외 조건은 먼저 적용합니다. 음식 선호 선택과 문장이 다르면 문장이 우선합니다. 입력이 비어 있으면 현재 폼을 제출합니다. 전송 버튼과 Enter는 같은 경로를 사용합니다.
- 종류·재료 선택지는 전체 카탈로그로 만들고 추천 결과에서만 제한을 검사했습니다. 이제 선택지·목록·추천·대안에 같은 제한 조건을 사용합니다. 후보가 없는 종류와 재료는 숨깁니다. 제한을 변경하면 이전 대화의 부적합 추천 카드도 숨깁니다.
- 비건의 확인 필요 후보 모드에서 동물성 재료의 포함 가능성을 허용했습니다. 이제 포함 가능성에 고기·해산물·달걀·유제품·꿀이 있으면 후보에서 제외합니다. 확인된 비건 표시도 명시된 충돌 정보를 덮어쓰지 못합니다. 현재 저장소 43개 음식에는 이 기준을 만족하는 비건 후보가 없어, 없다는 안내를 보여줍니다.
- 알레르기가 있다고 했지만 항목을 아직 선택하지 않았으면 음식 추천을 중단하고 알레르기 질문으로 돌아갑니다.
- 모든 봇 말풍선과 답변 선택지 묶음에 배경과 테두리를 적용했습니다. 순한맛을 고르지 않았는데 유지했다고 안내하던 대안 문구도 실제 상태에 맞췄습니다.
- 메인의 언어 변경 시 챗봇 제목·질문·버튼도 바뀌고, 미제출 식단·알레르기 선택과 작성 중인 문장은 유지합니다.
- 언어 화면의 안내 카드 좌우 경계를 언어 선택 버튼과 맞췄습니다.

## 검증 범위와 한계

UI 검사는 운영 DB 대신 저장소 음식 43개를 제공하는 로컬 모의 API를 사용했습니다. 실제 운영 DB, 실제 휴대폰·네이버 앱, 사진 앱 저장 완료 및 지도 SDK는 검사하지 않았습니다. DB에 명시된 재료 및 포함 가능성은 차단하지만, DB에 누락된 원료나 실제 식당의 교차 접촉까지 보장할 수는 없습니다. 이에 대한 식당 확인 안내는 유지했습니다. 운영 DB 변경과 공개 서비스 배포는 포함하지 않습니다.

## 후보 없음 안내 보완

일치 후보가 0개이면 조건 수정을 제공하며, 비건의 경우에는 식단 다시 선택도 제공합니다. 실제 후보를 모두 본 경우에만 “이전에 본 음식 다시 보기”를 표시하며, 후보 없음과 소진 안내를 구분합니다. 음식이 없다는 답변에는 적용된 식단·알레르기·제외·선호·종류·맵기를 함께 표시합니다. 동의한 대안 검색에서 이미 완화한 선호는 적용 조건으로 잘못 표시하지 않습니다. 네 언어의 후보 없음·소진·대안·다시 보기·DB 삭제를 검사했습니다. 실제 UI에서 비건·우유 알레르기·돼지고기 제외가 답변에 표시되고 재시도 버튼이 없는 것을 확인했습니다.
## 비건 후보 없음 안내 보완

비건으로 검색한 결과가 없으면 현재 조건에 맞는 등록 후보가 없다는 점과, 비건 메뉴 제공 여부·원재료를 음식점에 직접 문의하라는 안내를 표시합니다. 식단 다시 선택과 조건 수정 버튼을 제공합니다. 식단 다시 선택은 프로필 질문만 열고 기존 식단·알레르기·제외 항목은 자동으로 해제하지 않습니다. 4개 언어 단위 검사와 실제 로컬 UI에서 확인했습니다.
