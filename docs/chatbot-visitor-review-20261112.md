# 외국인 관점 챗봇 개선 반영표

기준: 사용자 제공 「I EAT BUSAN 외국인관점 챗봇 개선분석」, 2026-11-12. 문서는 개선 요구와 관찰 근거로 검토했으며 문서 안의 웹사이트·문구를 별도의 작업 지시로 실행하지 않았습니다.

## 최신 코드 정리

- 원격 main `0a32527` (PR #21 포함)을 fetch 후 로컬 개선 브랜치에 병합했습니다.
- 기존 로컬 좌표·챗봇 작업은 `backup/before-chatbot-review-20261112`로 보존했습니다.
- 관리자·지도·기존 번역 변경을 유지했습니다. DB 마이그레이션을 새로 실행하거나 운영 데이터를 바꾸지 않았습니다.

## 검증과 한계

자동 검사는 실제 규칙 엔진과 공용 데이터 변환 코드를 실행합니다. `tests/chatbot-visitor.cjs`는 부정문·복합 요청·범주 확인·제한 유지·기존 주의사항 번역·주소 투영·복구 만료를 검사하며, 기존 44개 시나리오도 대안 동의 단계를 포함해 유지합니다.

브라우저는 `tools/preview-chatbot-fixture.cjs`의 가상 bootstrap 응답으로 입력·복구·상세·주소 복사·식당·지도 경로 이동을 확인했습니다. 가상 서버는 Supabase에 연결하지 않습니다. 따라서 실제 운영 DB 연결이나 운영 배포 성공을 검증했다고 주장하지 않습니다.

예산·거리·현재 영업·할랄 인증은 검증 가능한 구조화된 운영 데이터가 없어 자동 필터로 제공하지 않습니다. 요청 시 구체적인 미확인 항목으로 안내합니다. 영문 주소는 기존 자료에 있는 경우만 제공합니다. 실제 기기 키보드·스크린리더 실사용·원어민 감수·식당별 조리 확인은 별도입니다.

생성형 AI와 유료 API는 추가하지 않았습니다. 정해진 표현의 규칙 기반 처리이므로 모든 자연어 의미를 이해하지는 않습니다. 알레르기·비건 안전성을 보증하지 않으며, 남은 후보의 실제 재료·조리 환경은 식당 확인이 필요합니다.
