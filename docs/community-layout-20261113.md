# 커뮤니티 버튼 배치 검사 — 2026-11-13

## 수정

- 글쓰기를 카테고리 줄 오른쪽, 새로고침 아래로 이동했습니다. 카테고리만 가로로 스크롤되며 글쓰기 버튼은 같은 줄에 남습니다. 로그인 확인과 글쓰기 경로를 유지했습니다.
- 커뮤니티 고정 글쓰기 버튼과 전용 여백, 사용하지 않는 FAB 스타일을 제거했습니다.
- 댓글 등록·음식 상세 하단 버튼 위에 챗봇을 배치하고, 741~959px에서도 하단 메뉴 위에 표시합니다.
- 프로필·글쓰기 화면에서는 챗봇을 상단의 빈 공간에 배치합니다. 글쓰기 카테고리는 챗봇 공간을 남기고 좁은 화면에서 줄바꿈합니다.
- 지도 식당 목록은 챗봇 쪽에 여백을 두어 상세 보기 버튼을 가리지 않습니다.
- 데스크톱 게시글 카드의 너비에 좌우 여백을 반영해 가로 넘침을 제거했습니다.
- 수정한 JS/CSS의 캐시 버전을 갱신했습니다.

## 브라우저 검사

수정 전 1280×720에서 글쓰기와 챗봇의 사각형이 겹쳤고, 게시글 상세의 댓글 등록 버튼도 겹쳤습니다. 수정 후에는 각 화면의 고유 요소가 나타날 때까지 기다려 렌더링 완료 후 측정했습니다.

- 320×740, 390×844, 768×1024, 960×720, 1440×900, 가로 화면 844×390에서 커뮤니티·음식 상세·게시글 상세·프로필·글쓰기·지도 상세: 36개 조합.
