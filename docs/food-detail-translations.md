# 음식 상세 페이지 번역

영어·중국어 간체·일본어 번역은 js/data/food-detail-locales.js에 저장됩니다. 원문을 수정하지 않고 표시 시 번역하며, 브라우저에서는 외부 번역 서비스를 호출하지 않습니다.

- 음식 소개, 8개 상세 정보, 유래, 먹는 방법, 알레르기 안내, 식당 목록과 식당 상세 안내를 포함합니다.
- 음식명 아래 작은 한국어 이름만 원문으로 유지합니다.
- 경로·식당 식별자·주소 검색·지도 좌표·사진 파일명과 링크는 번역하지 않습니다.
- 공개 원고의 번역 1494개를 포함합니다. 식당 정보 변경 시 번역 사전도 함께 갱신해야 합니다.
