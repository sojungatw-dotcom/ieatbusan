# 프로필 사진

마이페이지 → 프로필 수정 → 사진 선택에서 기기의 이미지를 고릅니다. 원형 미리보기를 확인한 뒤 저장하기를 눌러 업로드합니다. 기본 이미지로 변경도 저장하기를 눌러 확정합니다. 사진을 고르기만 하고 화면을 나가면 서버 사진은 바뀌지 않습니다.

- 선택 파일은 최대 10MB이며, 브라우저에서 읽을 수 있는 이미지 형식을 지원합니다. SVG는 받지 않습니다.
- 로컬에서 중앙을 정사각형으로 잘라 256×256 JPEG로 변환합니다. 서버는 JPEG 형식과 최대 256KiB 크기를 다시 검사합니다.
- `public.ieb_profiles.avatar_path`에는 본인 계정 폴더의 Storage 경로만 저장합니다. 로컬 파일 경로나 만료되는 URL은 DB에 저장하지 않습니다.
- `ieb-avatars`는 비공개 버킷입니다. 회원은 자신의 파일만 조회·업로드·삭제할 수 있습니다. 기존 프로필 소유자 RLS를 유지합니다.
- bootstrap은 현재 회원의 사진에 1시간짜리 서명 URL을 발급합니다. 마이페이지와 프로필 수정 화면은 해당 URL을 사용하며, 파일이 없거나 불러오지 못하면 이니셜을 표시합니다.
- 사진 경로와 닉네임·소개·국가는 한 번의 프로필 PATCH로 저장합니다. 사진을 지정하지 않은 기존 요청은 기존 사진을 유지합니다.
- 교체·제거 후 이전 사진을 정리합니다. 업로드 또는 프로필 저장 실패 시 새 파일을 정리하고 이전 프로필을 유지합니다. 회원 탈퇴 시 사진 버킷도 정리합니다.

## 적용 및 검증

2026-11-06 연결된 IEATBUSAN 프로젝트에 `add_private_profile_avatars`를 적용했습니다. 재적용 가능한 SQL은 CLI로 생성한 `supabase/migrations/20261106004839_add_private_profile_avatars.sql`에 있습니다. 기존 회원 데이터는 변경하지 않습니다.

`node tests/profile-avatar.cjs`는 로컬 크롭·압축, 잘못된/큰 파일, 선택 순서·화면 이동, 저장·재조회·교체·삭제, 실패 시 정리, 사용자 ID/경로 위조 차단과 탈퇴 정리를 검증합니다. 서버 API 테스트의 Storage 응답은 모의 응답입니다.

실제 DB에서는 임시 계정과 메타데이터를 트랜잭션 안에서 사용해 본인 저장, 다른 사용자 폴더 업로드·조회 차단, 타인 프로필 변경 차단과 비회원 접근 차단을 확인했습니다. 검증 데이터는 롤백했으며 실제 사용자 사진을 업로드하지 않았습니다. 브라우저 파일 선택·미리보기·저장 UI는 별도 메모리 전용 로컬 서버에서 확인했습니다.

DB는 적용 완료이며 웹 코드의 커밋·push·배포는 별도입니다.
