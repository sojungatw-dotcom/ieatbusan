## 잘못 연결하지 않은 후보

- 대한콩국 남천점의 2025년 방문 글은 존재하지만 연결된 네이버 장소 `1738415345`는 현재 찾을 수 없는 페이지였습니다. 이 후보를 사용하지 않고 현재 부산 주소와 메뉴가 함께 확인되는 센텀점으로 연결했습니다.
- 과거 부산 여여재의 헛제사밥 소개를 현재 운영 근거로 재사용하지 않았습니다.
- 네이버 검색이 반환한 민들레식당은 김치찌개·두루치기 등 실제 게시 메뉴를 확인해 헛제삿밥 근거에서 제외했습니다.

## 데이터 반영과 복구

- 기본 카탈로그: 음식 45 → 43종, 음식/식당 연결 160 → 164개. 유지된 음식과 기존 식당의 순번은 동일합니다.
- DB: `ieb_foods` 원본 45행 유지. `andong-heotjesatbap`, `yonggung-sundae`의 `content.catalogStatus`만 `archived`로 지정하고 API 응답에서 제외합니다. 좋아요·찜·게시글·댓글을 삭제하거나 재작성하지 않습니다.
- 식당 마스터: 기존 155행은 유지하고, 신규 부산 매장 4행과 음식별 연결을 추가해 159행입니다. 신규 행의 `verified_at`은 공개 안내를 대조한 시각이며 전화·현장 확인 시각을 뜻하지 않습니다.
- DB 제외 복구: 해당 두 음식 행의 `content`에서 `catalogStatus` 키를 제거합니다. 기본 카탈로그도 이 커밋 이전의 해당 2개 원고 항목을 복원해야 오프라인 상태까지 일치합니다.
- `supabase/migrations/20261106061000_review_empty_food_restaurants.sql`을 대시보드에서 먼저 ROLLBACK 검증 후 COMMIT했습니다. 기존 식당 행 및 대상 외 음식 데이터가 바뀌면 전체 트랜잭션이 실패하도록 검사합니다.

화면 레이아웃·스타일·동작은 변경하지 않았습니다. 서버의 추가 변경은 보관 처리된 음식 2종이 DB 새로고침으로 다시 노출되지 않게 하는 응답 필터 한 줄입니다.
