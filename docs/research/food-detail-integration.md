# 음식 상세 원고 반영

원고: `docs/research/food-detail-manuscript.md` — 최종 수정본 v2 반영 (조사일 2026-11-03).

- 원고 34개 중 기존 9개 음식은 ID와 기존 사진 출처를 유지해 갱신하고, 25개를 추가했습니다. 기존 원고 밖 음식 11개를 포함한 전체 목록은 45개입니다.
- 상세 정보 / 먹는 방법 / 알레르기·식단 / 부산 식당 리스트를 원고 순서대로 표시합니다. 사진 바로 아래 버튼으로 섹션을 이동합니다.
- 음식 하단 식당 목록은 기존 사진 배너와 식당 상세 화면을 공통으로 사용합니다. 식당 주소·메뉴·가격·영업시간·휴무는 상세 화면의 해당 항목에서 보여주며, 목록의 조사 안내는 접어서 확인합니다.
- 기존 식당의 순서와 좌표를 유지하고 원고의 같은 이름 식당은 기존 항목을 갱신합니다. 원고에만 있는 식당은 뒤에 추가하여 기존 찜 키를 보존합니다.
- 식당 자료 100건은 해당 메뉴·유사 메뉴 구분, 게시 가격·영업시간, 미확인 사항, 출처와 조사일을 보존합니다. 현재 영업 확인이나 추천 순위로 바꾸지 않습니다.
- 좌표 미확인 자료는 지도 핀을 만들지 않습니다. 지도 목록에서 상세를 열거나 원고의 주소 검색 링크를 이용합니다.
- 새 음식은 사진 준비 중 이미지를 사용합니다. 원고 음식의 칼로리와 확인되지 않은 좋아요 수는 화면에서 표시하지 않습니다.
- 원고 외국어 음식명은 검수 전 이름으로 반영했습니다. 상세 번역을 새로 생성하지 않고 한국어 원고와 번역 검수 대기 안내를 보여줍니다.
- 먹는 방법 공개 보류 등 원고의 유보 표현을 보존합니다. 팀 내부 메모와 편집 목표 부족 수는 이용자 화면에서 제외합니다. 초기 후보 20개 및 추가 발굴 후보 10개는 원본 문서에서 확인할 수 있습니다.
- 기존 5개 슬라이드 및 4초 자동 넘김, 로그인·커뮤니티 API 동작은 유지합니다.

외부 사이트의 현재 영업·가격·재료를 새로 검증한 작업은 아닙니다. 원고의 조사 시점과 확인 상태를 그대로 반영했습니다.

## 공통 상세 화면 개정

- 원고에 있는 34개와 기존 11개 음식 모두 하나의 음식 상세 템플릿을 사용합니다. 상세 표 8개 항목 → 음식 소개·유래 → 흰색 먹는 방법 카드 → 알레르기 카드 → 식당 배너 순서로 표시합니다. 기존 자료에 없는 값은 확인 필요로 표시합니다.
- 로컬 팁은 모든 음식에서 제거했습니다. 최종 원고의 통합 소개를 반영하고, 비교 설명·주문 예문·상세 정보 근거·먹는 방법 근거·성분 판단 근거는 화면에서 제거했습니다.
- 식당 배너와 기존 상세 UI를 유지하며 주소·메뉴·가격·영업시간·휴무를 해당 항목에 표시합니다. 식당별 출처는 이용자 화면과 생성 데이터에서 제거합니다. 원고 문서의 출처 기록은 내부 보관용으로 남습니다.

- 먹는 방법 카드에서 소스·양념, 곁들이는 음식, 주문 전에 확인, 최소 주문·혼밥·맵기 조절, 먹을 때 주의 및 하단 단계 안내 문구를 제외했습니다. 소개 문장과 번호별 먹는 순서, 별도 알레르기 정보는 유지합니다.

## 2026-11-05 알레르기 및 예시 참여 수 정리

- 전체 45개 음식은 같은 연분홍 알레르기 카드, 성분 배지, 설명 문단 형식을 사용합니다. 원고의 기본·가변 성분과 식단 주의 문구는 유지합니다.
- 첫 화면 제목을 추천 향토음식 5선으로 변경했습니다. 기존 5개 슬라이드와 4초 자동 넘김은 유지합니다.
- 음식·식당의 임의 좋아요 수와 커뮤니티 예시 좋아요 수를 제거했습니다. 좋아요가 없으면 숫자를 숨기며, 실제 게시글 좋아요는 DB 관계 테이블로 계산합니다. 찜은 전체 좋아요 수에 합산하지 않습니다.
- 연결된 Supabase에서 예시 댓글 8개와 seed_likes 값을 정리했습니다. 실제 사용자 댓글 1개와 실제 좋아요 관계는 유지했습니다. 재실행 가능한 정리 SQL은 supabase/cleanup-example-engagement.sql에 보관합니다.
- 기존 식당 순서·좌표와 원고 식당의 주소 기반 지역 구분을 함께 유지하도록 지도 데이터 연결을 보완했습니다.
- tests/engagement.cjs 및 음식·지도·API·인증·자동 넘김 회귀 검증으로 확인합니다.

## 식당 상세 주소·영업일 표시

- 식당 상세 정보는 위치 아이콘의 주소와 시계 아이콘의 영업일·시간 / 휴무일 두 항목으로 통일했습니다. 지도와 별도의 대표 메뉴 영역은 유지합니다.
- 상세 주소 필드 또는 원고의 주소가 있으면 그대로 표시하고, 상세 주소가 없는 식당만 기존 지역 정보를 사용합니다. 영업일·시간과 휴무일이 없는 경우 확인 필요로 표시하며 임의의 영업일을 생성하지 않습니다.
