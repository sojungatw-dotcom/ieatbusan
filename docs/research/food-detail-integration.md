# 음식 상세 원고 반영

원본: `docs/research/food-detail-manuscript.md` (조사일 2026-11-03).

- 원고 34개 중 기존 9개 음식은 ID와 기존 사진 출처를 유지해 갱신하고, 25개를 추가했습니다. 기존 원고 밖 음식 11개를 포함한 전체 목록은 45개입니다.
- 상세 정보 / 먹는 방법 / 알레르기·식단 / 부산 식당 리스트를 원고 순서대로 표시합니다. 사진 바로 아래 버튼으로 섹션을 이동합니다.
- 식당 자료 100건은 해당 메뉴·유사 메뉴 구분, 게시 가격·영업시간, 미확인 사항, 출처와 조사일을 보존합니다. 현재 영업 확인이나 추천 순위로 바꾸지 않습니다.
- 좌표 미확인 자료는 지도 핀을 만들지 않습니다. 지도 목록에서 상세를 열거나 원고의 주소 검색 링크를 이용합니다.
- 새 음식은 사진 준비 중 이미지를 사용합니다. 원고 음식의 칼로리와 확인되지 않은 좋아요 수는 화면에서 표시하지 않습니다.
- 원고 외국어 음식명은 검수 전 이름으로 반영했습니다. 상세 번역을 새로 생성하지 않고 한국어 원고와 번역 검수 대기 안내를 보여줍니다.
- 먹는 방법 공개 보류 등 원고의 유보 표현을 보존합니다. 팀 내부 메모와 편집 목표 부족 수는 이용자 화면에서 제외합니다. 초기 후보 20개 및 추가 발굴 후보 10개는 원본 문서에서 확인할 수 있습니다.
- 기존 5개 슬라이드 및 4초 자동 넘김, 로그인·커뮤니티 API 동작은 유지합니다.

원고 재생성:

```powershell
node tools/import-food-manuscript.cjs . docs/research/food-detail-manuscript.md
node tools/build-static.cjs
node tests/food-manuscript.cjs
node tests/deployment.cjs
node tests/home-carousel.cjs
node tests/async-regressions.cjs
```

외부 사이트의 현재 영업·가격·재료를 새로 검증한 작업은 아닙니다. 원고의 조사 시점과 확인 상태를 그대로 반영했습니다.
