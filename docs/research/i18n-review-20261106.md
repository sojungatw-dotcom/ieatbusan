# 다국어 UI/UX 표기 점검 — 2026-11-06

한국어·영어·중국어 간체·일본어의 공통 문구, 화면별 제목과 버튼, 보조기술용 이름, 언어 전환 및 긴 문구의 배치를 점검했다. 음식·식당의 사실 자료, 운영정보, 사진과 보관 상태는 변경하지 않았다.

로그인 관련 영어는 `Log in / Log out`으로 통일했다. 영어 수량 문구는 `Restaurants: 1`과 같은 라벨 형식으로 단수에서도 어색하지 않게 표시한다. 언어 선택 항목의 보조 이름은 영어로 통일했고, 키보드로 언어를 바꾼 뒤 선택 버튼의 포커스를 유지한다. 선택 상태와 CSS는 `aria-pressed`를 기준으로 함께 갱신한다.

## 실제 기능과 안내 일치

- 영어로 대체 표시되던 중국어·일본어 이용 안내와 개인정보 안내를 추가했다.
- 통합 시점의 원격 `430b443` GA4 연동을 유지하고, 추가된 분석 수집 항목·로그인 식별자 연결·전송 제외 항목 안내도 네 언어에 반영했다.
- FAQ·개인정보 안내·탈퇴 확인문에서 브라우저에만 저장된다는 과거 설명을 현재 서버 저장/계정 삭제 동작에 맞게 수정했다.
- `.example` 문의 이메일의 수신 불가 상태를 명시하고, 근거 없는 2영업일 회신 약속을 제거했다.
- 알림 예시 및 푸시 알림 미제공 상태를 표시했다. 게스트에게 계정 탈퇴 버튼을 노출하지 않는다.
- 지도 설정 오류는 이용자가 활용할 수 있는 외부 지도 링크를 안내하도록 정리했다.
- 일부 음식의 상세 원고, 식당명·주소·조사 원문은 한국어로 남아 있다. 이를 번역된 자료로 오인하지 않도록 언어 선택 안내, 홈과 상세 화면에 설명하고 `lang="ko"`로 구분했다. 번역된 제목·라벨에는 선택 언어가 적용된다.

## 검증

- 공통 번역 키 270개 × 4개 언어의 키·빈 값·치환 변수와 불필요한 한국어 혼입 검사.
- 지도 문구 키와 치환 변수 일치 검사.
- 게스트·회원 화면과 음식 43종/식당 연결 164개의 상세를 포함한 1,020개 렌더링 검사. 렌더링 후 카탈로그 불변 확인.
- 이전 `app.js`에 새 회귀 검사를 실행하면 실패하고 수정본에서는 통과함을 확인.
- 기존 검사 포함 Node 검사 26개 및 정적 빌드 통과.
- 로컬 모의 계정/API로 실제 앱을 열어 4개 언어 전환과 포커스 유지 확인. 320·430·1280px에서 주요 화면 108개 조합의 가로 넘침·깨진 이미지 없음. 320px의 프로필과 영어·일본어 홈에서 발견한 폭 문제를 수정 후 재검사했다.
- 실제 Supabase 계정의 생성·탈퇴, 실제 지도 타일/좌표 조회 및 배포 후 실서비스 검증은 이번 점검에 포함하지 않았다. 별도 원어민 감수자를 통한 검수도 수행하지 않았다.
