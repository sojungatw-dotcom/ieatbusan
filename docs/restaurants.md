## 데이터 확인 상태

이번 작업은 기존 서비스 데이터를 이전한 것입니다. 새로 영업 정보를 크롤링하거나 현재 영업 여부를 확인한 작업은 아닙니다. 영업시간 79개, 휴무일 126개는 기존의 확인 필요 상태를 유지합니다. `verified_at`은 NULL이며, 출처를 확인한 뒤 갱신합니다. 실제 식당 좋아요 기록은 아직 없어 초기 합계는 0입니다. 기존 찜 기록을 좋아요로 임의 전환하지 않았습니다.

## 웹 연결

bootstrap에서 식당 마스터를 읽어 음식별 원래 위치에 공통 주소·영업시간·휴무·좌표·좋아요 수를 반영합니다. 따라서 식당 테이블을 수정하면 다음 웹 데이터 조회에 반영됩니다. 기존 URL 및 찜 키는 유지하고, 식당을 합친 경우에도 음식별 메뉴·가격·주의사항은 보존합니다. 지정된 네이버 링크를 빈 값으로 덮지 않습니다.

식당 하트의 기존 찜 동작은 유지합니다. 향후 식당 좋아요 저장에 사용할 `public.ieb_set_restaurant_like(target_id,is_liked)`도 준비했습니다. 같은 사용자의 중복 추가를 방지하고 본인 선택만 취소할 수 있으며, 회원 탈퇴 시 해당 사용자의 좋아요를 정리합니다. 일반 사용자는 식당 정보나 카운터를 직접 수정할 수 없습니다.
