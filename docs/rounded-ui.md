# 무보소 디자인 시스템 · 2026-11-12

## 방향과 기준
사용자 제공 레퍼런스의 큰 라운드 카드, 명확한 제목, 사진 중심 구성을 유지한다. 다홍 #CC4936 / 한지 미색 #F5F2EC / 베이지 #E5D5C2는 보존한다. 모바일과 데스크톱은 같은 컴포넌트를 사용하며 열 수와 내비게이션 배치만 바꾼다.

- 색상/간격/모서리/그림자/모션/폰트: css/design-tokens.css가 단일 기준이다.
- 앱 컴포넌트: css/rounded-ui.css. 기존 app.css/map.css/responsive.css는 구조와 동작을 유지한다. 새 시각 수정은 이 파일에 모은다.
- 독립 문서(관리자/챗봇): css/rounded-embedded.css에서 같은 토큰을 사용한다.
- 카드 24px, 큰 패널 32px, 버튼/입력창 16px, 작은 배지 8~12px. 내부 패딩 20~24px, 주요 패널 24~32px.
- Pretendard Variable 1.3.9를 로컬 제공한다. 중국어/일본어는 기존 Noto Sans SC/JP 폴백 유지. 라이선스 assets/fonts/OFL-Pretendard.txt.
- 제목 700~750 / 본문 400~500 / 버튼 700. 제목 1.22~1.4, 본문 1.6~1.9 행간. 한국어 단어 단위 줄바꿈과 긴 문자열 비상 줄바꿈을 병행한다.
- 버튼은 최소 44px, 주요 버튼 52px. 화살표는 별도 고정 폭 열에서 텍스트와 수직 중앙 정렬한다.
- SVG 기능 아이콘 24 좌표계/1.75 선, 음식 카테고리 24 좌표계/1.5 선. 선 끝과 연결은 round.
- 원본 로고는 보존한다. 배경 제거 파생본 assets/brand/muboso-transparent.png를 앱/챗봇에서 사용한다. 새 파생본은 imagegen으로 배경을 제거한 결과이며 원본 픽셀과 완전 동일하다고 주장하지 않는다.
- 로고 첫 등장 620ms, 호버 2px 상승, 눌림 0.97배. 앱 내 라우팅 때 등장 효과를 반복하지 않는다. reduced-motion에서는 효과를 끈다.
- 카드 폭에 맞춘 캐러셀 이동/현재 페이지 복원. 마지막 카드도 시작점에 정렬되도록 마지막 여백을 둔다.
- 고정 메뉴/CTA/댓글창 공간은 유지하며 챗봇 런처와 CTA 겹침을 방지한다.

## 협업
### 2026-11-13 컴포넌트 보완
- 이미지가 들어간 목록 카드: 외곽 24px, 패딩 12px, 이미지 12px로 안팎 곡률을 맞춘다. 카드 끝까지 채우는 사진은 부모가 클리핑한다.
- 정보표와 조건 목록: 항목 사이에만 구분선. 데스크톱 2열 정보표는 첫 행 두 칸을 제외하고 위쪽 선을 적용하므로 마지막 행 아래 선은 생기지 않는다. 내 댓글 카드의 잔여 인라인 아래 선도 제거했다.
- 챗봇 헤더는 브랜딩 행과 도구 행을 분리한다. 호스트와 iframe의 도구는 44×44px, 아이콘 24px, 간격 8px, 가장자리 16px를 공유한다. 호스트가 닫기/확대를 소유하는 기존 동작은 유지한다.
- 전송 버튼을 textarea 바깥의 별도 열로 옮겨 스크롤바와 겹치지 않게 했다. `field-sizing` 지원 환경에서는 내용에 따라 52–120px로 확장하며 미지원 환경은 52px 높이에서 스크롤한다.
- 입력/선택 버튼 간격 8px, 검색창 전후 간격, 목록 패딩과 음식 이미지 곡률을 정리했다. 현재 저장소의 챗봇은 로컬 음식 데이터 버전이며 첨부 화면의 DB 새로고침 버튼은 존재하지 않아 기능을 추가하지 않았다.
- 지도 원본 경로/지역 링크는 유지하고 viewBox의 빈 여백을 줄였다. 1200px 이상에서 지도 열을 확대한다. 제목/안내/지역 선택 영역의 좌상단 정렬은 유지한다.
- 브라우저 확인: 320/390px 챗봇에서 가로 넘침 없음, 여러 줄 입력과 실제 전송, 1440px 기본/확대 도구 정렬, 조건 마지막 선, 음식 카드. 음식 정보표 320/1440px 마지막 선 0px. 지도 390/1440px 한국어 및 1280px 영어 라벨/경계 확인. 정적 서버 사용, 운영 DB 쓰기 없음.
- 빌드 및 chatbot(44 시나리오 포함), map-districts, map-contracts, public-entry, i18n, deployment 검사 통과. 증거: `verification/component-spacing/`.

고정 메뉴의 바깥 여백도 예약된 메뉴 영역이다. `.persistent-nav`의 고정 배경은 상단 전체와 데스크톱 좌측 레일(모바일에서는 하단)을 덮어 스크롤 내용이 모서리/여백으로 비치지 않게 한다. 배경 990, 메뉴 1000의 순서를 유지하며 배경은 입력을 가로채지 않는다. 관리자 전체 화면에는 생성하지 않는다. 2026-11-12 홈/해산물 목록의 1440px 데스크톱 및 390px 모바일 스크롤 화면에서 확인했다.
