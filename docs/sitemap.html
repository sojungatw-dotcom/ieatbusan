접근·저장·외부 연결

첫 실행에서 로그인 또는 게스트 둘러보기 → 최초 언어 선택 → 홈으로 이동합니다. 언어 선택을 마친 재진입은 홈으로 갑니다. 로그인하지 않고 게스트도 아닌 상태에서는 로그인·언어·약관·개인정보·사진 출처만 직접 열 수 있습니다. 게스트의 글쓰기·좋아요·댓글은 로그인으로 유도하며, 프로필 수정도 로그인 화면을 표시합니다. 로그인·게시글·댓글·찜은 브라우저 localStorage 기반 데모입니다. 설정의 로그아웃과 탈퇴는 별도 화면이 아닌 동작이며, 탈퇴는 확인 후 데이터를 초기화합니다. 지도 외부 링크는 새 탭으로 연결됩니다. 배포는 사용자 요청으로 보류 중입니다.
