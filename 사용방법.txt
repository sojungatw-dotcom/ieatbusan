부산·경남 향토음식 기본 기능 시안

실행: index.html을 브라우저에서 여세요. 설치나 빌드가 필요 없습니다.

파일 구성
- index.html: 음식 목록, 상세 페이지, 커뮤니티 구조
- style.css: 기본 배치와 모바일/PC 반응형 처리
- app.js: 예시 데이터, 검색, 상세 정보, 섹션 이동, 게시글 저장·삭제

구현 기능
- 초기 화면 상단 추천 음식 5개: 모바일 좌우 스와이프, PC 이전·다음/번호 버튼, 키보드 좌우 방향키
- 추천 영역 아래 음식 사진과 간단한 정보 목록: 아래로 스크롤하여 탐색
- 부산/경남 지역 필터, 음식명·지역 검색
- 음식 클릭 시 상세 화면으로 이동
- 음식 사진 영역 바로 아래 버튼으로 상세 정보/먹는 법/판매 식당/알레르기·주의사항 이동
- 가상 식당 정보 표시와 실제 식당 지도 검색 링크
- 커뮤니티 글 작성, 목록 보기, 글 삭제
- 브라우저 저장소(localStorage) 사용: 새로고침 후에도 같은 브라우저에서 글 유지

데이터 수정
- app.js 맨 위 foods 배열에서 음식 정보를 수정하세요.
- 음식 사진은 각 음식의 image 값을 images/사진파일.jpg 같은 경로로 바꾸고 해당 사진을 넣으세요.
- 현재 사진은 '사진 준비 중' 표시이며, 식당은 명확히 표시된 가상 데이터입니다.
- 음식 설명, 재료, 알레르기 정보도 기능 확인용 예시입니다. 공개 서비스 전에 실제 출처와 식당별 성분 확인이 필요합니다.

현재 범위
- 디자인과 컬러 작업은 진행하지 않았습니다. 기본 무채색 배치만 적용했습니다.
- 서버, 회원가입, 로그인, 사용자 간 게시글 공유는 연결하지 않았습니다.
- 브라우저 데이터를 삭제하면 게시글도 삭제됩니다.
- file:// 환경에서 저장소를 제한하는 브라우저는 저장이 불가능할 수 있으며 안내 메시지를 표시합니다.
